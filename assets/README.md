# Eigene Grafiken

## truck.png — Fahrzeugsymbol auf der Karte

Liegt in diesem Ordner eine Datei `truck.png`, wird sie auf der Karte
anstelle des Sinnbilds 🚛 verwendet. Ohne Datei bleibt das Sinnbild —
es ist also nichts weiter zu tun, wenn keine eigene Grafik gewünscht ist.

**Anforderungen**

* Format: PNG mit durchsichtigem Hintergrund
* Größe: 64 × 64 Bildpunkte, dargestellt wird mit 24–26 Punkten
* Ausrichtung: Fahrzeug zeigt nach **rechts**. Die Gegenrichtung
  spiegelt das Programm selbst.
* Der Umriss sollte kräftig sein, damit das Fahrzeug auf der Karte
  auch über Wald, Wasser und Stadtflächen erkennbar bleibt.

Nach dem Ablegen der Datei die Seite einmal neu laden.
