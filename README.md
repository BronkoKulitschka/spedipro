# Spedipro 95 — v0.1.0

Erste lauffähige Smartphone-Version nach der Referenz „Spedipro 95 auf dem Smartphone“.

## Enthalten
- Windows-95-/Pixelart-Hauptmenü
- Firmenübersicht
- Aktive-Touren-Karte
- 12 Hauptmenü-Schaltflächen
- echte Navigation zu allen 12 Bereichen
- Demo-Daten für Fuhrpark, Aufträge, Touren, Personal, Kassenbuch etc.
- Aufträge können angenommen werden
- Werkstattauftrag zieht Geld ab und schreibt ins Kassenbuch
- Nachrichten können gelesen/ungelesen geschaltet werden
- Einstellungen werden gespeichert
- Zustand wird lokal im Browser gespeichert
- responsive Darstellung für Smartphone, Tablet und Desktop

## Installation mit bestehendem update.sh
Das ZIP `spedipro-0.1.0.zip` in den Download-Ordner legen und anschließend im bestehenden Repo:
`./update.sh`

Das Archiv enthält absichtlich den Ordner `spedipro/`, weil update.sh aus `$HOME` entpackt.
